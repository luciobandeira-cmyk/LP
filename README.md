# Alumglass Esquadrias — landing page

Página estática (HTML + CSS, sem dependências de build).

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `alumglass-lp`) e envie **todo o conteúdo desta pasta** para a raiz: `index.html`, a pasta `img/` e o arquivo `.nojekyll`.
2. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta `/ (root)` → **Save**.
3. Em 1–2 minutos o site fica em `https://SEU-USUARIO.github.io/alumglass-lp/`.

## Trocar fotos
As imagens estão em `img/`. Para trocar, substitua o arquivo mantendo o mesmo nome. As fotos atuais são ilustrativas (Unsplash, licença gratuita) e devem ser substituídas por fotos reais das obras.
